# 笔记撰写规范（生成每篇视频笔记前必须完整遵守）

## 一、核心规范：技术名词首现讲解（ELI5 结构化版）

文档中每个技术名词（术语、框架、方法名、产品名）**第一次出现时**，紧跟一段「快速上手讲解」，按以下三段结构组织：

1. **一句话本质**：它是什么——用一句直白的话讲清其核心，**不使用类比**。
2. **结构化拆解**（分点列出，清晰化）：
   - 它由哪几部分组成 / 解决什么问题；
   - 它是怎么工作的（关键机制，2-4 点）。
3. **作用定位**：它在本文档的主题中扮演什么角色；读者掌握它之后，在后续的知识体系或实际工作中能用它做什么、为什么值得花时间理解。

讲解要求：
- 通俗易懂、结构清晰、**禁止使用类比**（不要"就像/好比"式解释，用拆解和因果说明）；
- 宁可多分点，不要堆砌术语；讲解本身里若出现新术语，同样适用本规范；
- 同一概念全文只讲一次，后文直接使用；多个相近名词可合并为一条讲解。

## 二、逻辑链条规范

- 撰写详细内容之前，先完成**「整体逻辑链条梳理」**章节：用编号步骤列出全文的推理/叙事主线（A → B → C → …），并说明每一环为什么成立、环与环之间如何衔接。
- 详细章节的每个部分开头，用一句话标注它对应逻辑链的哪一环（如「对应链条第 2 环」）。
- 文档收尾时对照逻辑链**逐环回收**：每条结论落回主线，指出是否有尚未闭环的环节（如有，明确写出它是开放问题）。

## 三、精华版开头规范

- 文档最开头设置**「精华版」**章节：全文的高度凝练浓缩。
- 要求：
  - 不遗漏全文任何要点；
  - 精华版自身必须逻辑闭环——只读精华版也能理解主线、关键概念与结论；
  - 篇幅控制在全文的 15% 以内。
